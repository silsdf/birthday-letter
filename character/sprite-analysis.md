# RPG Tiny Characters Sprite Sheet Analysis

Source folder:
`D:\游戏素材库\角色行走动画素材\RPG Tiny Characters Asset Pack - Free`

## Sheet Types

- Complete character sheets: `128 x 192`
  - Grid: `4 columns x 6 rows`
  - Frame size: `32 x 32`
  - Columns: animation frames
  - Rows: direction/action rows

- Split layer sheets under `split/body`, `split/head`, `split/fitting`: `192 x 192`
  - Grid: `6 columns x 6 rows`
  - Frame size: `32 x 32`
  - Valid animation frame columns: `0, 2, 3, 5`
  - Mostly empty alignment columns: `1, 4`

## Direction Rows Used

- Row `0`: front / down-facing
- Row `1`: back / up-facing
- Row `2`: side-facing, used for right movement
- Left movement: generated by horizontally mirroring row `2`

Rows `3`, `4`, and `5` are matching alternate rows for front/back/side. The first implementation keeps to rows `0..2` because they are enough for RPG idle and walk movement.

## Animation

- Idle: frame column index `0`
- Walk: frame column index sequence `0, 1, 2, 3`
- Split sheet source columns for that sequence: `0, 2, 3, 5`

The renderer never draws a full sheet directly. It crops one `32 x 32` frame per layer, then composites body, fitting, and head.
